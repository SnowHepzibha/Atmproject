# 🏦 ATM Banking Management System

## 📌 About the Project

The ATM Banking Management System is a web-based application developed using Python and Django. This project helps users perform basic banking operations through a simple and user-friendly interface.

It allows customers to deposit money, withdraw money, check their account balance and view their recent transaction history. It also provides an admin section to manage customer accounts.

## 🚀 Technologies Used

- **Frontend:** HTML, CSS
- **Backend:** Python, Django
- **API:** Django REST Framework
- **Database:** SQLite
- **Tools:** VS Code, Git, GitHub

## ✨ Features

### 👤 Customer Features
- Check account balance.
- Deposit money into an account.
- Withdraw money from an account.
- View mini statements.
- View recent transaction details.

### 🔐 Admin Features
- Admin login.
- Create new customer accounts.
- View all customer accounts.
- Update customer account details.
- Delete customer accounts.
- Manage customer deposits and withdrawals.

## ⚙️ Installation and Setup

Follow these steps to run the project on your computer.

**Step 1: Clone the Repository**

```bash
git clone https://github.com/YOUR-USERNAME/ATM-Banking-Management-System.git
```

**Step 2: Open the Project Folder**

```bash
cd ATM-Banking-Management-System
```

**Step 3: Create a Virtual Environment**

```bash
python -m venv venv
```

**Step 4: Activate the Virtual Environment**

For Windows:

```bash
venv\Scripts\activate
```

**Step 5: Install Required Packages**

```bash
pip install -r requirements.txt
```

**Step 6: Apply Database Migrations**

```bash
python manage.py migrate
```

**Step 7: Create an Admin Account**

```bash
python manage.py createsuperuser
```

**Step 8: Run the Development Server**

```bash
python manage.py runserver
```

**Step 9: Open the Application**

Open your browser and visit:

```text
http://127.0.0.1:8000/
```
